# Velora Circle

## Project Guidelines
- Velora Circle is a privacy-first collaboration web application built with TanStack Start, React 19, Vite, and Tailwind CSS.
- Keep the strict privacy UX rules intact: normal members must never see member counts, full member directories, or online member tallies.
- Role-based permissions are enforced: only Owners and Admins access the management panel and aggregate statistics.
- Maintain responsive, accessible design with semantic markup and proper focus states.
